Support

Help information for people using ChatByKarnav.

How to get help

ChatByKarnav does not currently offer a dedicated support email address or private support-ticket service.

For technical problems, bugs, or suggestions, you can use the project's GitHub issue tracker. Please check existing reports before opening a new one and describe the problem clearly, including the steps needed to reproduce it.

Open GitHub issue tracker

Account and sign-in help

If you cannot sign in, check that you are using the correct email address and password. If password recovery is available for your account, use the password-reset option provided by the app.

Safety and unwanted contact

Use the blocking and reporting controls available in the app when dealing with unwanted contact or inappropriate content. If you believe someone is in immediate danger, contact the appropriate local emergency services.

Protect your information

Important: GitHub issue reports may be publicly visible. Never include passwords, sign-in codes, private chat messages, personal documents, payment details, or other sensitive information. Remove or mask personal information from screenshots and logs before sharing them.

For information about using the service, read the Terms and Conditions if available.
